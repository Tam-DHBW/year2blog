## Tech Stack

### Frontend

| Layer | Technology |
|-------|-----------|
| Language | JavaScript |
| Framework | React with React Router |
| Build Tool | Vite |
| Styling | nes.css |
| Hosting | AWS S3 + CloudFront |

### Backend

| Layer | Technology |
|-------|-----------|
| Language | Rust |
| Runtime | Tokio |
| Serialization | Serde |
| Compute | AWS Lambda (via cargo-lambda) |
| API | AWS API Gateway |
| Auth | AWS Cognito |
| AI | AWS Bedrock Agents |
| Database | AWS DynamoDB |
| Logging | AWS CloudWatch Logs |
| CDN | AWS CloudFront |
